## 环境与复现

本机 macOS 26.5.1 arm64；uv 0.12.3；Python 3.12.13 / 3.10.20；Node.js 22.23.3；npm 11.12.1。Python 与 Node 依赖分别由 uv.lock、package-lock.json 锁定。Node 22 用于文档检查，四个 Python 示例不需要 Node。

在仓库根目录执行：

~~~sh
uv sync --locked --python 3.12
uv run ruff check examples tests
uv run pytest -q
UV_PROJECT_ENVIRONMENT=.venv-310 uv sync --locked --python 3.10
UV_PROJECT_ENVIRONMENT=.venv-310 uv run pytest -q
npm ci
npm run lint:md
npm run test:docs
node scripts/check_docs.mjs --python .venv/bin/python
npm run check:diagrams
git diff --check
git remote -v
~~~

## 已知提示与未覆盖范围

pytest-socket 阻止了 urllib3 导入时的 IPv6 loopback 能力探测，来源为 `urllib3.util.connection._has_ipv6("::1")`；它不是模型请求。ADK 的 JSON_SCHEMA_FOR_FUNC_DECL 实验提示和替身缺少 usage metadata 的日志仍保留。Python 3.10 另有 OpenTelemetry 依赖的 SelectableGroups 弃用提示。警告没有被全局隐藏，测试期间互联网 socket 仍被禁止。

真实模型调用、MCP/A2A 网络集成、实时音视频、数据库后端、并发冲突、跨进程恢复、外部动作 exactly-once、云部署和 GitHub Actions 远程执行均未验证。竞品仅核查官方固定资料，没有安装实测或进行性能排名。链接返回 200 不等于其内容永远不变，固定提交与核查日期用于控制引用边界。

保留一个 Minor 改进项：工具测试目前统计 FunctionCall 事件及结果，没有另行包装真实 get_weather 函数来独立统计执行次数。可在后续测试中包装并委托原函数，补强“实际恰好执行一次”的证据；当前未发现重复执行缺陷。

对审阅者列出的范围边界逐项决定如下；这些边界不表示相关能力已被本仓库验证：

| 决定 | 原因 | 可能遗漏的影响 |

| 不作竞品性能或生产可靠性排名 | 只有固定官方资料比较 | 选型仍需实际工作负载试验 |
