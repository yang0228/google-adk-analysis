# 从示例到生产：需要做出的决定

这是一份设计核查表，不是部署已经通过的证明。先用自己的业务负载回答这些问题，再决定系统架构。

| 决策 | 需要产出的证据 | 对应边界 |
| --- | --- | --- |
| 用户身份怎样映射到会话 | 鉴权链、跨用户访问测试 | Session ID 不是授权 |
| 哪些数据需要持久化 | 后端选择、迁移、备份与恢复演练 | InMemory 不跨进程 |
| 重复工具调用如何处理 | 幂等 ID、去重或补偿测试 | 事件保存不等于外部事务 |
| 谁能批准动作 | 审批身份、过期、拒绝和重复响应测试 | RequestInput 只是暂停机制 |
| 模型怎样更换 | 同题评估、schema/工具/实时兼容检查 | BaseLlm 不保证能力同构 |
| 并发与失败怎样收敛 | 超时、限流、取消、冲突写测试 | 图并发限制不覆盖所有资源 |
| 如何判定质量退化 | EvalSet、指标阈值、模型与配置版本 | 离线控制流测试不是质量评估 |
| 日志保存什么 | 脱敏、保留、访问范围、trace 策略 | 事件可能包含业务数据 |
| 部署在哪 | IAM、镜像、存储区域、网络和费用预算 | SDK 与托管平台分别评估 |

部署路径及固定源码入口见[评估与部署](../capabilities/evaluation-observability-deployment.md)。Google Cloud 是 ADK 的一组集成选项，自托管同样需要生产运维。本仓库没有执行在线评估、数据库集成、故障恢复或任何云部署。
